# Repeato frontend

React and Vite customer and business-owner interface. Run the entire project from the parent folder with `npm run dev`.

The Vite development server proxies `/api` requests to the Node API on port 3001.

The public landing page includes a responsive five-section footer; its in-page links and customer/business portal actions use existing screens. Help and legal summaries are informational drafts and should be reviewed before launch. Customer and owner sign-in continue to use the live backend email/password flow; SMS and OTP authentication are not configured.
